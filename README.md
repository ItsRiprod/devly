# Devly - The Development Companion

This mod is meant to exist in your development server - never actually touch production.

It's to add several QOL features to make your development experience smoother!


As of right now, it only works as an aid to **Patchly**

# Patchly Integration

### Automatic **`.patch`** generation
```
/devly minify --all
```

This will detect all override assets in your mod and convert them into minimal `.patch` - getting rid of all the overlap and leaving just the difference.

### Automatic `.patch` syncing
```
/devly monitor
```
Enables monitoring the autogenerated `_Patchly` pack.

While enabled, any edits to the assets present will sync back and be reflected in the original `.patch` file. This lets you use the Asset Editor to manage your assets and quickly iterate without having to open VSCode
